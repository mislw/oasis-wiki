# UGCAskQ MCP 使用说明

> 本文档帮助开发者快速上手 UGCAskQ MCP，了解如何将 AI 助手接入绿洲启元编辑器，并高效完成玩法内容的制作。

> **⚠️ 重要提示：实验性功能**
>
> UGCAskQ MCP 目前处于**早期实验阶段**，功能仍在持续迭代中，可能存在不稳定的情况。在使用前，请务必注意以下事项：
>
> - **备份工程**：每次使用 MCP 前，请先保存并备份当前工程文件，避免因 AI 误操作导致数据丢失或损坏
> - **逐步验证**：建议每次只让 AI 执行一小步操作，确认效果无误后再继续，避免一次性执行大量不可逆操作
> - **结果不一定准确**：AI 生成的配置参数、节点结构等可能不完全符合预期，使用后请人工检查关键内容
> - **功能范围有限**：并非所有编辑器模块都支持 MCP 操作，具体支持范围见下文"支持的编辑器功能"章节

## 概述

UGCAskQ MCP（Model Context Protocol）是绿洲启元编辑器的 AI 协作接口，允许 Claude、Cursor 等 AI 助手直接读取和操作编辑器中的各类内容，让开发者可以通过自然语言来完成复杂的编辑器操作。

连接后，AI 助手能够感知当前编辑器的状态（当前选中了哪些对象、场景里有什么、哪个技能配置了什么），并代替开发者执行操作，例如批量添加 Actor、配置技能属性、生成行为树节点等。

> **推荐做法：** 使用更强的大语言模型，可以获得更准确、更流畅的操作体验。

## 快速接入

### 第一步：打开 MCP Server

在编辑器顶部菜单栏依次点击 **窗口 → 开发者工具 → MCP Server**，打开 MCP Server 控制面板。

面板顶部会显示当前服务状态。若显示 **Running（Port: 33444）** 等字样（绿色），说明服务已正常启动，可以直接进行第二步。

若服务未启动，点击面板内的 **Start Server** 按钮手动启动。

> **提示：** 如果端口连接失败，可以在面板中修改 Port 值后重新点击 Start Server。

### 第二步：在 AI 客户端中配置 MCP

以 Claude 为例，在项目根目录（或工作区根目录）创建 `.mcp.json` 文件，内容如下：

```json
{
  "mcpServers": {
    "ugcaskq": {
      "type": "sse",
      "url": "http://127.0.0.1:33444/sse"
    }
  }
}
```

将 `33444` 替换为 MCP Server 控制面板中显示的实际端口号。保存后重新启动 AI 客户端，即可连接到编辑器。

> **Cursor / VS Code 用户：** 在对应客户端的 MCP 设置中，以 SSE 类型添加上述地址即可。

### 第三步：验证连接

连接成功后，向 AI 助手发送一条简单问题来确认：

- *"当前场景里有哪些 Actor？"*
- *"你现在能在编辑器里做哪些操作？"*

AI 助手能够正确回答，说明连接已生效。

## MCP Server 控制面板说明

| 配置项                      | 说明                               | 推荐设置                        |
| --------------------------- | ---------------------------------- | ------------------------------- |
| **Port**                    | 服务监听端口，默认 33444           | 默认即可，冲突时修改            |
| **Enforce Level**           | PRV 安全策略级别                   | `Observe`（推荐，警告但不阻断） |
| **Enable MCP Call Logging** | 是否记录每日调用日志               | 开启                            |
| **Idle Boundary (sec)**     | 空闲超时阈值，超过后开启新的任务段 | 90 秒（0 表示关闭）             |

点击 **Open Log Folder** 可以打开日志目录，查看当天所有 MCP 调用记录（`Saved/log/MCP_YYYYMMDD.log`）。

## 支持的编辑器功能

MCP 当前已覆盖绿洲启元编辑器中以下模块的操作能力：

### 场景与 Actor 管理

在世界场景中放置和管理 Actor 是 MCP 最基础的能力之一，支持：

- 在场景中**创建和放置 Actor**，指定位置、旋转和缩放
- **查询和修改** Actor 的属性（Transform、标签、父子关系）
- **批量操作**，例如一次性在指定区域放置多个同类 Actor

**使用示例：**

> *"在坐标 (0, 0, 100) 处放置一个 BP_Rock 资产，并将其缩放设置为 2"*
> *"选中场景中所有名为 'Barrel' 的 Actor，统一移动到 Z=50 的高度"*

---

### 技能编辑器

支持通过 AI 完成技能的创建和属性配置，适合快速搭建技能原型：

- **创建新技能**，指定技能类型和基本属性
- **读取现有技能**的配置内容，用于核查或二次修改
- 配置技能的**基础数值参数**（如冷却时间、消耗值等）

**使用示例：**

> *"帮我创建一个近战技能，冷却时间 3 秒，消耗能量 20"*
> *"读取'闪现'技能的当前配置，列出所有参数"*

---

### 物品编辑器

支持对玩法物品进行创建和配置：

- **创建物品**，设置物品类型、名称、图标等基础信息
- **查询物品**列表，按类别筛选
- 修改物品的**数值属性**

**使用示例：**

> *"创建一个消耗品类型的物品，名称为'急救包'，描述为'恢复 50 点生命值'"*

---

### 行为树

AI 可以辅助搭建怪物和 NPC 的行为逻辑，支持：

- **创建和读取**行为树资产
- 添加和配置行为树**节点**（Selector、Sequence、Task 等）
- 为节点**挂载 Lua 脚本**，扩展自定义行为逻辑

**使用示例：**

> *"帮我给 Boss 行为树添加一个巡逻节点，当血量低于 30% 时切换到逃跑状态"*
> *"查看当前行为树的节点结构"*

---

### 蓝图编辑器

支持对蓝图资产的基础操作：

- **创建**新蓝图资产，指定父类
- **查询**蓝图变量和函数列表
- 添加**变量**（Bool、Int、Float、Vector 等类型）
- 向**黑板**中添加键值

**使用示例：**

> *"在角色蓝图中添加一个名为 'IsAttacking' 的 Bool 变量"*
> *"查看当前蓝图有哪些公开变量"*

---

### UI 编辑器（UMG）

支持 AI 辅助进行 UI 控件的创建和布局：

- **创建 UMG 蓝图**资产
- 在 Widget 中**添加控件**（Button、Text、Image、ProgressBar 等）
- 设置控件的**位置、大小和锚点**
- 配置控件的**文本内容和颜色**

**使用示例：**

> *"创建一个血量条 Widget，包含一个 ProgressBar 和一个显示数字的 Text 控件"*
> *"把确认按钮的背景色改成蓝色，文字改为'开始游戏'"*

---

### 数据表（配置表）

支持对游戏内配置数据进行读写：

- **读取**数据表的行数据
- **添加和修改**数据行
- 支持常见配置场景，如物品表、技能表、掉落表

**使用示例：**

> *"在物品配置表中添加一行，ID 为 1001，类型为武器，攻击力 50"*
> *"查看技能配置表中 ID 为 2001 的那一行"*

---

### 实体编辑器

支持对游戏内实体（怪物、NPC 等）进行属性配置：

- **查询**实体的当前配置
- **修改**实体的属性（生命值、移速、攻击距离等基础参数）
- 读取实体挂载的**组件信息**

**使用示例：**

> *"把精英小怪的生命值改为 800，移速提高 20%"*

---

### 资产查找与视窗控制

- **搜索资产**：按名称或类型在内容浏览器中查找资产路径
- **视窗操作**：控制编辑器摄像机的位置和朝向，聚焦到指定 Actor

**使用示例：**

> *"帮我找到名称包含 'Weapon' 的所有静态网格资产"*
> *"把视角移动到场景原点，俯视角度"*

## 推荐使用方式

### 用法一：批量内容生成

当需要在场景中批量放置同类内容时，MCP 能显著节省时间。例如：

> *"按照以下坐标列表，在场景中放置 10 个 BP_Bush：(100,0,0), (200,0,0)...，缩放随机在 0.8 到 1.2 之间"*

---

### 用法二：技能原型快速迭代

在策划阶段，可以用自然语言快速配置技能原型，让 AI 帮你填写各种参数：

> *"我想做一个冲刺技能：按下后主角向前冲 500 单位，期间无敌 0.3 秒，冷却 8 秒，请帮我在技能编辑器里创建这个技能并配置好基础参数"*

---

### 用法三：配置核查与批量修改

当需要核查或修改大量配置时，可以让 AI 读取后汇总：

> *"读取所有近战类技能，列出它们的冷却时间，找出冷却时间超过 10 秒的技能"*

---

### 用法四：UI 布局辅助

描述你想要的界面样式，让 AI 帮你搭建控件结构：

> *"帮我做一个简单的游戏结算界面：顶部是大字标题，中间是分数显示，底部是返回大厅按钮"*

---

### 用法五：行为树搭建

向 AI 描述 NPC 或怪物的行为逻辑，由 AI 负责节点的添加和连接：

> *"帮我给巡逻小怪搭建一个行为树：默认沿路点巡逻，发现玩家后追击，追击超过 15 秒或距离超过 800 则放弃追击回到巡逻"*

## 常见问题

**Q: AI 连接后说"找不到服务器"怎么办？**
A: 确认 MCP Server 控制面板显示为 Running 状态；检查 `.mcp.json` 中的端口号与面板一致；重启 AI 客户端后重试。

**Q: 操作后编辑器没有反应？**
A: 部分操作完成后需要在编辑器中手动刷新对应面板。例如蓝图变量添加后，需要重新打开蓝图编辑器才能看到新变量。

**Q: 如何让 AI 了解当前场景的状态？**
A: 直接询问 AI "当前场景里有什么？"或"我现在选中了什么？"，AI 会主动通过 MCP 查询编辑器状态后回答。

**Q: 调用记录在哪里查看？**
A: 点击 MCP Server 面板中的 **Open Log Folder**，可以看到按天归档的调用日志（`MCP_YYYYMMDD.log`），用于排查异常操作。

**Q: 能不能一边在编辑器里操作，一边让 AI 辅助？**
A: 可以。AI 会感知到你当前选中的 Actor 或打开的编辑器，可以基于你的操作上下文提供针对性的帮助。

## 注意事项

- MCP Server 仅接受来自**本机**的连接，不支持远程访问。
- AI 的操作效果会直接反映在编辑器中，**建议操作前先保存工程**，避免误操作导致数据丢失。
- 复杂的多步骤操作（如完整的关卡搭建），建议分阶段让 AI 执行，每个阶段确认效果后再继续。
- 部分编辑器（如特效编辑器、音频编辑器等）当前暂无 MCP 接口，操作这些模块时仍需在编辑器中手动完成。
